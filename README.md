# Discoord
Best Self-hosted Tool for **Dis**tant **Coord**ination. 

Final project for Web Programming and Applications (CSIE 5210) in 2026 Spring.
## Introduction
Discoord 是一款兼具臨場感與趣味性的通訊軟體，你可以：

+ 建立或加入不同房間，與他人交流各式主題
+ 自訂 Avatar 與個人狀態，在 2D 虛擬空間中自由探索
+ 透過語音或文字即時聊天，與好友保持聯繫
+ 在黑板上發布公告，讓所有成員都能共同編輯與更新內容

Link (for PC only):  https://discoord.pythonanywhere.com/
## Usage
```bash
git clone https://github.com/richardlaiis/discoord-group11.git


# Install dependencies
pip install -r requirements.txt

# Create the database
python manage.py migrate

python manage.py runserver
```
After doing all the required steps, just type the url `127.0.0.1:8000` in your web browser.

Have fun!
